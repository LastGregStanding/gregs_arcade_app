I originally taught myself programming by building various games in the browser using JavaScrit/HTML/CSS.
I didn't want all those games to go to waste, just collecting dust on my computer. So I decided to
create a full stack web app where users can create accounts and play the games. The app stores users
game data and allows users to compete with eachother on the sites leaderboard. The stack I used for
this project was React/NodeJS/MySQL.
